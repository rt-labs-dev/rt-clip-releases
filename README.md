# rt-clip

Clipboard history in your tray, synced through your own Google Drive. For Windows and macOS.

**Download, features and privacy policy: [apps.rtobo.dev/rt-clip](https://apps.rtobo.dev/rt-clip/)**

This repository holds the published installers under [Releases](https://github.com/rt-labs-dev/rt-clip-releases/releases) and is the place to [report a problem or suggest something](https://github.com/rt-labs-dev/rt-clip-releases/issues). The source code is not public.
